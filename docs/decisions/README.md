# Decision log

Architecture Decision Records document choices that materially affect scope, data, architecture, evaluation, or governance.

Each record should include:

- status;
- date;
- context;
- decision;
- alternatives;
- consequences; and
- evidence references.

Statuses are `Proposed`, `Accepted`, `Superseded`, or `Rejected`.
