# Success metrics

## Workflow metrics

- Time required to prepare a candidate comparison
- Percentage of required fields with valid provenance
- Number of missing-data issues found before review
- Reviewer time required to understand score differences
- Percentage of briefs requiring factual correction
- Time required to identify the owner of one missing evidence item
- Percentage of displayed candidate-brief facts with visible source, date or
  unknown date, unit state, geography, quality, and evidence origin
- Percentage of reviewers who correctly distinguish missing evidence from an
  unfavorable observation in a standardized task
- Number of unresolved crosswalk, date, unit, definition, and geography-method
  issues surfaced in the brief
- Successful completion rate for selecting three candidates, opening one source
  detail, returning to readiness, and printing a redacted comparison
- Restricted-value exposure count in render, logs, screenshots, and print;
  target zero

## Calculation metrics

- Exact reproducibility for identical inputs and configuration
- Unit and range validation coverage
- Regression-test pass rate
- Rank stability under small approved weight changes
- Visibility of every metric contribution

## AI metrics

- Numeric-claim accuracy against structured results
- Source-attribution precision
- Unsupported-claim rate
- Human edit distance or correction count
- Reviewer preference versus a deterministic template

## Future model metrics

These require an approved outcome, cohort, and temporal design:

- Out-of-time predictive error
- Ranking quality on held-out mature clinics
- Calibration
- Stability across markets and clinic maturity
- Incremental value over current rules and analyst judgment

Do not use in-sample fit or feature importance alone as evidence that the system improves site decisions.
