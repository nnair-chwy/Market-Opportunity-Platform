# Non-goals

The first MVP will not:

- replace the real-estate or CVC analytics teams;
- make or approve a final site decision;
- automate leases, construction, licensing, staffing, or clinic activation;
- build a new production predictive model before roadmap alignment;
- infer causal drivers from observational clinic data;
- treat a score as expected revenue or profitability;
- use customer-level coordinates, PII, or clinical records;
- scrape internal dashboards or bypass access controls;
- edit Esri maps or production clinic records;
- allow an LLM to select weights or alter calculations;
- forecast performance without a defined outcome and temporal validation;
- copy whole Confluence, Tableau, Esri, or SharePoint artifacts into Git.
